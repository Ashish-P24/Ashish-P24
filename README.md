## `03` — Machine Status Monitoring

### Automated infrastructure monitoring for operational environments.

Built during my software engineering internship at **Thai Acrylic Fibre Co. Ltd.**, part of the Aditya Birla Group.

The system automates machine health checks, detects failures, and immediately alerts stakeholders instead of relying on manual monitoring.

```text
Machine Fleet
     │
     ▼
ICMP Health Checks
     │
     ▼
Scheduled Monitoring Engine
     │
 ┌───┴───────────────┐
 ▼                   ▼
Healthy             Failure
                       │
                       ▼
                Email Alerting
                       │
                       ▼
                 Web Dashboard
```

**Impact**

* Automated hourly health checks across **8–12 machines**
* Reduced manual monitoring effort by **65%**
* Reduced downtime detection time by **~50%**
* Real-time email alerts using Jakarta Mail
* AES-based encryption for sensitive credentials
* Dynamic JSON / Excel configuration
* No restart required for configuration updates

**Stack**

`Java` `Maven` `Jakarta Mail` `ICMP` `JSON` `Excel` `HTML` `CSS` `JavaScript`

→ **[View Repository](https://github.com/Ashish-P24/Machine-Status-Monitoring-System)**
